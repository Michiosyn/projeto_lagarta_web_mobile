# projeto_lagarta_web_mobile
Projeto "Lagarta" de Web Mobile - 

O intuito deste projeto é criar um site no qual auxilie famílias perdidas a se reencontrarem, ou a se adentrarem novamente na sociedade

Terá incluso como abas dentro do site:
- Sobre nós
- Home page
- Adoção
- Desaparecidos
- Acolhimento
- Doação de mantimentos
